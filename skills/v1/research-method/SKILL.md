# Дослідницький метод

1. Сформулюй реальне бізнес-рішення та напругу аудиторії. Зістав завдання із затвердженими знаннями й попередніми рішеннями власника. Розділи відомі факти, повідомлені твердження та припущення.
2. Склади до п'яти питань, відповіді на які змінять рішення. Для локальної OOH перевір дані площини; якщо обіцянка стосується відключень, перевір автономність і живлення обладнання; військові теми потребують позиції бренду. Питай лише релевантне, не підміняй невідомі відповіді загальними фразами.
3. Визнач метод і критерій пошуку до пошуку. Почни з первинних джерел, потім незалежних підтверджень. Записуй URL, назву, дату доступу, конкретне твердження, географію й обмеження. Не видавай уривок пошуку, стару ціну чи відсутній доступ за перевірений факт.
4. Для кожного висновку розділи спостереження, інтерпретацію та рішення. Verified потребує доступного джерела; reported означає атрибутоване, але не перевірене повідомлення; assumption потребує питання власнику. Дві сторінки одного пресрелізу не є двома незалежними доказами. Суперечності збережи й поясни.
5. Поверни щонайменше три корисні, відмінні кандидати, якщо джерела це дозволяють. Якщо ні - покажи прогалину й обмеження, не заповнюй кількість вигадкою. Для мінливих фактів указуй строк дії. Не затверджуй записи сам: лише draft, власник приймає рішення.
6. Дай висновок для брифу: що змінити, що перевірити, хто відповідає. Перевір references/checklist.md; звір упевненість з references/rubric.json і прикладами references/examples.md. Поверни один JSON поточного контракту.
