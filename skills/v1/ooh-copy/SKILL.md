# Текст зовнішньої реклами

1. Встанови носій, місце, напрям руху, швидкість контакту й відстань. Якщо площина невідома, постав власнику конкретне питання; не оголошуй макет готовим до друку. Відділяй концепцію від технічного релізу.
2. Витягни з брифу одну напругу аудиторії, одну продуктову користь, один доказ і один наступний крок. Перевір УТП, умови, географію та маршрут CTA за record_id/version. Відсутність у переданому брифі й відсутність у базі знань фіксуй окремо.
3. Для тем без світла уточни підтверджену автономність саме потрібної зони, вимоги до живлення роутера/ONU та обмеження. Для військових образів з'ясуй позицію бренду і доречність до контексту; не припускай дозволу. Не перетворюй ці питання на обов'язкові для нерелевантних брифів.
4. Згенеруй різні механізми, а не синоніми одного слогана. Для кожного подай заголовок, що видно першим, роль зображення, короткий CTA, причину зв'язку з продуктом і ризики. Орієнтуйся на одне повідомлення; точну допустиму довжину визначай за умовами площини, не вигадуй універсального нормативу.
5. Проведи тест трисекундного прочитання, swap бренду та перевірку, чи не повторює ілюстрація текст без нової інформації. Відкинь принаймні один слабкий напрям із конкретною причиною. Зістав варіанти за references/rubric.json.
6. Перелічи потрібні до релізу підтвердження й файли. Без реального файла, перевірених розмірів та специфікації постачальника не стверджуй «готово до друку». Поверни JSON поточного контракту й перевір references/checklist.md. Приклади оцінки дивись references/examples.md.
