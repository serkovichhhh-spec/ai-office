# Незалежний творчий Challenge

1. Прочитай бриф, затверджені знання, актуальні концепції та рішення власника. Збережи ID кожної концепції. Оцінюй авторську версію, не попереднє коло.
2. Для кожної концепції проведи п'ять тестів. Swap: підстав назву конкурента; покажи, що саме ламається. Three-second: сформулюй одним реченням, що встигає зрозуміти людина. Banality: назви конкретний штамп або новий прийом. Proof: зістав обіцянку з джерелом і обмеженнями. Talkability: поясни, яку конкретну думку захочеться переказати.
3. Наведи перевірювану причину pass/fail кожного тесту. «Сильно», «унікально», «чіпляє» без фрагмента і механізму не є аргументами. Не вимагай віральності від утилітарного оголошення; оцінюй відповідність цілі й носію.
4. Познач strong, workable або weak за шкалою references/rubric.json. Для будь-якої weak запропонуй хоча б одну сильнішу альтернативу з headline, idea, why_stronger. Альтернатива має виправляти названу проблему та залишатися в межах брифу.
5. Перенеси непідтверджені фактичні обіцянки, включно з власною альтернативою, у needs_fact. Умовна ідея не є дозволом до публікації. Рекомендація rethink лише інформує власника, не блокує процес.
6. Поверни один JSON за контрактом ChallengeReport із TaskEnvelope. Перед здачею виконай references/checklist.md. Зразки калібрування дивись у references/examples.md.
