# AI Office MCP: підключення ChatGPT і Claude

Адреса сервера: `https://ai-office-red.vercel.app/api/mcp`. Транспорт Streamable HTTP, лише POST, без стану.

## Інструменти (назви й схеми зафіксовані, v1)

| Інструмент | Що робить | Запис |
|---|---|---|
| `office_list_tasks` | задачі, призначені цьому виконавцю | ні |
| `office_get_task` | повний `TaskEnvelope.v1` | ні |
| `office_claim_task` | оренда задачі (`attempt_id`, `lease_token`); з `attempt_id`+`lease_token` продовжує оренду | так |
| `office_submit_result` | здає результат; невалідний за схемою → помилка, оренда лишається | так |
| `office_get_team_status` | черга по виконавцях, що чекає на власника | ні |

Після будь-якої зміни переліку чи схем інструментів у ChatGPT треба натиснути refresh у налаштуваннях підключення. Тому змінюємо їх лише з новою версією (v2), а не тихо.

## Авторизація

- **OAuth 2.1** (основний спосіб): authorization code + PKCE S256, динамічна реєстрація клієнта. Метадані: `/.well-known/oauth-protected-resource/api/mcp`, `/.well-known/oauth-authorization-server`.
  Власник входить в AI Office, обирає workspace і виконавця (ChatGPT або Claude) і натискає «Дозволити».
  Access-токен діє 1 годину, refresh 30 днів з ротацією. Повторне використання refresh чи коду відкликає всю сім'ю токенів.
- **Статичний токен у заголовку** `Authorization: Bearer aio_…` для клієнтів, де OAuth незручний. Створюється оператором: `select office.create_executor('pavutyna','claude_session','назва')`. Токен показується один раз; у базі зберігається лише sha256.
- Секрету в URL немає.

Відключення: панель «Виконавці» на сторінці workspace → «Відключити». Токени перестають працювати одразу, активні оренди звільняються.

## ChatGPT (Business)

1. ChatGPT → **Plugins** → **+** → **Add custom MCP server** (старий інтерфейс: Workspace Settings → Apps → Create).
2. Назва `AI Office`, URL `https://ai-office-red.vercel.app/api/mcp`, авторизація **OAuth** (поля клієнта лишити порожніми, бо працює динамічна реєстрація).
3. Відкриється сторінка AI Office: увійти, обрати PAVUTYNA і «ChatGPT», натиснути «Дозволити».
4. Перевірити, що знайдено 5 інструментів, і натиснути **Create**.
5. Тест у чаті: «візьми задачі AI Office». Записи (`claim`, `submit`) ChatGPT за замовчуванням підтверджує вручну.

Workspace Agents, розклади й API-тригери поки не вмикаємо, бо вони можуть витрачати кредити.

## Claude

Settings → Connectors → **Add custom connector** → URL `https://ai-office-red.vercel.app/api/mcp` → OAuth → у вікні AI Office обрати «Claude» → «Дозволити».
Після цього задача «AI Office: відпрацювати чергу» працює через цей конектор і не потребує доступу до Supabase.

## Безпека

- Кожен токен прив'язаний до одного виконавця в одному workspace. Він дозволяє лише 5 операцій над задачами цього виконавця.
- Затверджувати, змінювати бриф чи знання через MCP неможливо.
- Результат після закінчення оренди, після зміни вхідних артефактів або для неактуальної задачі не застосовується. Він зберігається в `execution_attempts.result` як пропозиція.
- Rate limiting поки лише на реєстрацію клієнтів (30 за годину). Обмеження на виклики інструментів в планах (RISKS.md).
